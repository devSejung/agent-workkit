# agent-workkit

낯선 과제에서도 제공된 Codex와 **요구 파악 → 기존 구현 탐색 → 재사용 판단 → 작은 변경 → 실제 검증**을 진행하기 위한 작업 도구함이다. 정답, 완성형 앱, 특정 기술 스택을 제공하지 않는다.

기본 사용은 Markdown 읽기다. 세팅 때 Caveman의 공개 Skill·LICENSE 두 파일만 내려받는다. 패키지 설치, 개인 API 키, 외부 AI, MCP 등록, 브라우저·컴퓨터 자동 조작은 필요 없다. 실행 명령과 제출 방식은 제공 프로젝트에서 찾는다.

## 바로 사용하기

짧게 요청하려면 다음을 사용한다. 공개 주소는 `https://github.com/devSejung/agent-workkit`이다.

```text
devSejung/agent-workkit을 별도 참고 폴더에 클론해서 START.md 읽고 세팅해.
```

**기본은 본시험 세팅**이다. 환경·Git·Caveman 상태를 짧은 표로 출력하며, 사전체험 전체를 다시 돌리지 않는다. Caveman은 필요할 때 `짧게`로 켜고 `보통으로`로 끈다. 자동 발견이 되는 환경에서는 `$caveman`도 쓸 수 있다. [다운로드와 호출 방법](docs/caveman.md).

Linux/Debian 계열이면 실제 OS·셸을 확인해 해당 명령을 사용한다. 브라우저 화면 직접 접근을 전제하지 않고 **로컬 실행/HTTP 확인 + 사용자의 내장 Browser 확인**으로 작업한다. 웹의 실제 포트·바인딩과 버튼 결과를 구분한다. 캡처는 시도하지 않고 허용된 내부 이미지 전달 방법을 확인한다.

로컬 Git 이력은 관리하되 사전체험·본시험에서 모든 push·원격 쓰기·외부 업로드는 금지한다. 서술형은 AI·복사·붙여넣기 없이 진행한다. 사전체험 절차는 따로 `사전체험 점검해`라고 요청한 경우만 사용한다.

1. 최신 공식 안내와 과제 README·적용되는 AGENTS.md를 먼저 확인한다. 제공된 버전의 Codex CLI를 사용하며 업데이트하지 않는다.
2. **제공 환경의 Codex에게** 공개 URL에서 이 저장소를 가져오도록 요청한다. 과제와 분리된 새 폴더가 우선이며, 접근 범위상 어렵다면 허용된 작업 공간 안의 충돌 없는 별도 폴더를 쓴다. 제공 파일이나 전역 설정을 덮어쓰지 않는다.
3. 과제 디렉터리에서 작업하며 가져온 `START.md`의 **실제 경로**를 지정해 읽게 한다. 상세 문서는 해당 상황에서만 읽는다.

특정 revision으로 재현하려면 아래 `<검증한 커밋/태그>`에 실제 확인한 값을 넣는다. 커밋을 따로 지정하지 않은 짧은 요청에서는 가져온 실제 revision을 확인한다.

```text
현재 폴더는 과제 프로젝트다. 최신 공식 안내와 이 프로젝트의 README·적용되는 AGENTS.md를 먼저 확인해라.
공개 저장소 https://github.com/devSejung/agent-workkit 의 <검증한 커밋/태그>를 제공 환경의 도구로 충돌 없는 별도 폴더에 가져와라.
기존 README·AGENTS.md·설정은 덮어쓰지 말고, 가져온 START.md의 실제 경로를 읽어 이번 작업의 보조 지침으로 사용해라.
필수 요구와 중요한 불확실성을 정리하고, 기존 코드 및 관련 공개 구현에서 재사용할 부분과 놓친 예외를 짧게 검토해라.
첫 작은 변경과 실제 검증까지 진행하고, 실행하지 못한 것은 미검증으로 남겨라.
자료·코드·작업 결과를 외부로 보내거나 push하지 말고, 실제 기록은 과제 환경 안에만 남겨라.
```

이미 가져왔다면 `“<실제 경로>/START.md를 읽고 현재 과제에 적용해라”`로 시작할 수 있다. 가져오기 실패 시 [환경과 대안](docs/environment.md)을 사용한다.

| --- | --- |

| [작은 구현](playbooks/implement.md) | 기존 구조 안에서 실행 가능한 작은 변경을 만들 때 |

| [환경과 대안](docs/environment.md) | 가져오기·CLI·이미지·자동 인식·선택 기능을 확인할 때 |
| [15분 사전체험](docs/rehearsal.md) | 사전체험 점검을 명시적으로 요청한 경우에만 |

| [공개 전 점검](docs/publishing.md) | 이 준비 저장소를 공개하거나 갱신하기 직전 |
| [AGENTS.md](AGENTS.md) | **이 도구함 자체를 수정하는 에이전트용** 지침 |

자동 실행기나 Skill 전체 번들은 넣지 않았다. Caveman도 원본의 최소 두 파일만 제공 환경의 AI가 다운로드한다. 자동 발견이 안 되면 경로로 읽는다. `AGENTS.md`·Skill 적용 범위와 권한 옵션은 [환경 문서](docs/environment.md)에 있다.

브라우저 자동화는 일괄 금지하지 않는다. 해당 도구·방식이 공식적으로 허용되고 제공 환경에서 실행 가능하면 UI 검증에 활용한다. 허용 여부가 불명확한 상태에서는 기본 구성에 넣지 않는다. 도구 이름만으로 Computer Use 금지의 예외라고 가정하지 않는다.

## 공개물과 과제 기록의 경계

- 이 저장소에는 일반 지침과 **비어 있는** 양식만 둔다. 회사 코드·내부 자료·키·개인정보·개인 응시 링크·실제 문제·작업 결과를 넣지 않는다.
- 실제 기록은 과제 환경에서 허용된 별도 로컬 경로에 작성한다. 준비 저장소의 템플릿을 직접 채우지 않는다. 기록 경로는 제출 대상 여부도 확인한다.
- 인터뷰는 작업 방식의 참고다. 이번 과제의 채점표나 허용 기능을 증명하지 않는다.
- 제공 환경에서 가져온 공개 저장소는 안내된 기간까지 공개 상태를 유지한다. 이 준비의 전제는 **2차 예선 결과 통지까지 유지**하는 것이다.
