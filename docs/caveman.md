# 세팅할 때 Caveman 다운로드

요청할 때만 응답을 짧게 만드는 공개 Skill이다. 이 저장소에서 별도 버전을 만들거나 전체 번들을 복사하지 않는다. **제공 환경의 Codex가 세팅 중 아래 원본 두 파일을 다운로드**한다. 패키지·플러그인·실행 스크립트 설치는 필요 없다.

## 원본 고정

사용자가 지정한 Caveman 내용과 일치하는 공개 커밋 `4863bc20d9738df2d64870761334b119c3e0c7ce`를 사용한다.

| 저장할 파일 | 다운로드 URL |
| --- | --- |
| `SKILL.md` | https://raw.githubusercontent.com/JuliusBrussee/caveman/4863bc20d9738df2d64870761334b119c3e0c7ce/skills/caveman/SKILL.md |
| `LICENSE` | https://raw.githubusercontent.com/JuliusBrussee/caveman/4863bc20d9738df2d64870761334b119c3e0c7ce/LICENSE |

원본 바이트의 SHA-256은 아래와 같다. 이미 제공된 해시 도구가 있으면 비교한다. 별도 도구 설치는 하지 않는다.

```text
SKILL.md  cf4cffbca62e6377195345a428b23c5654259fca281340450ddd521fbe340770
LICENSE   5eb826cd03151bcc7cce3f80d40e87733237fedfc6c36d6908aca5fd650a0bdb
```

해당 버전은 MIT, Copyright (c) 2026 Julius Brussee다. 현재 main의 내용·라이선스와 섞지 않고 위 커밋의 고지를 함께 보존한다. 원본의 토큰 절감 수치는 이 환경에서 검증한 보장이 아니다.

## 다운로드와 발견

1. 과제 루트와 허용된 쓰기 범위를 확인한다. 제공 버전이 지원하면 최종 위치는 **과제 루트의 `.agents/skills/caveman/`**다. 기존 경로·파일·심볼릭 링크의 실제 대상을 먼저 확인하며 허용 범위 밖으로 쓰지 않는다. 옆 폴더의 도구함만으로 과제의 Skill 자동 발견이 된다고 가정하지 않는다.
2. 기존 Skill을 재사용하려면 **SKILL.md와 LICENSE 둘 다** 이 원본과 일치하는지 확인한다. 하나라도 다르거나 확인되지 않으면 기존 파일을 그대로 보존하고 별도 경로를 선택한다. 이름이 같다는 이유로 덮어쓰거나 같은 Skill로 판단하지 않는다.
3. 새 다운로드는 **Skill 검색 경로 밖의 충돌 없는 임시 폴더**에 먼저 받는다. 두 파일의 성공적인 다운로드, 실제 본문과 MIT 고지, 가능한 경우 위 해시를 확인한다. HTML·잘린 파일·해시 불일치·LICENSE 누락이면 최종 검색 경로에 배치하지 않는다. 실패한 임시 파일은 미완료라고 표시하고 재사용하지 않는다. 기존 파일은 건드리지 않는다.
4. **두 파일 검증이 끝난 뒤에만** 완성된 폴더를 비어 있는 최종 위치에 배치한다. 그사이 목적 경로가 생겼으면 다시 충돌로 처리한다. `.agents` 쓰기가 제한되거나 기존 Skill과 충돌하면 허용된 별도 참고 경로에 완성본을 두고 경로로 읽는다. 전역 설정·기존 README·AGENTS.md를 바꾸지 않는다.
5. 제공 CLI가 `/skills`나 `$` 선택을 지원하면 `caveman`의 **실제 출처 경로가 위에서 검증한 파일인지** 확인한다. 이름만 보이거나 다른 파일을 가리키면 이번 다운로드의 자동 발견은 미확인이다. 이때 `$caveman` 사용을 안내하지 말고 `짧게`와 검증한 절대 경로 방식으로 진행한다. **다운로드됨 / 같은 파일이 자동 발견됨 / 명시 경로로 사용 가능**을 구분한다.
6. 다운로드가 막히면 실패 이유를 짧게 알리고, 현재 대화에서 “핵심만 짧게 답해”로 계속한다. Caveman 때문에 본시험 전체를 멈추거나 업데이트·재시작·전역 설정 변경을 반복하지 않는다. 설치·적용됐다고 주장하지 않는다. 사전체험 파일이 본시험에 남아 있다고 가정하지 않는다.

원본 설치 스크립트나 `npx` 설치기는 실행하지 않는다. 다운로드한 지침이 공식 안내·시험 경계·프로젝트 지침을 바꾸지 않는다. 첫 다운로드 실패 뒤 대안이 없으면 본 작업을 진행하고, 같은 실패를 계속 재시도하지 않는다.

기본 세팅은 파일 준비까지이며 Caveman 모드는 켜지 않는다. 실제 저장 경로를 세팅 결과에 한 번 알려준다. 자동 인식 갱신에 새 세션이 필요한 버전이라도 현재 작업을 불필요하게 재시작하지 말고 경로 방식으로 바로 사용한다.

## 짧은 호출

아래는 터미널 셸 명령이 아니라 **Codex 대화창에 입력하는 요청**이다.

| 입력 | 동작 |
| --- | --- |
| `짧게` 또는 `caveman 켜` | START.md를 읽은 에이전트가 다운로드한 SKILL.md의 실제 경로를 읽고 적용 |
| `$caveman` | CLI가 **검증한 동일 파일**을 가리킨다고 확인했을 때만 명시 호출 |
| `$caveman lite` / `$caveman ultra` | 동일 파일 연결이 확인된 경우의 강도 선택; 경로 방식은 `짧게 lite` / `짧게 ultra` |
| `보통으로` / `normal mode` / `stop caveman` | Caveman 해제 |

`/caveman`이 Codex의 내장 슬래시 명령이라고 가정하지 않는다. 명령으로 인식되지 않으면 일반 문장 `짧게`를 쓰거나 **“<실제 경로>/SKILL.md 읽고 적용해”**라고 요청한다. 새 세션에서는 필요한 모드를 다시 요청한다.

짧게 답하더라도 실패·미검증·불확실성·필수 조건을 생략하지 않는다. 코드·명령·경로·오류 원문은 정확히 유지한다. 복잡한 순서나 되돌리기 어려운 행동은 명확한 문장으로 설명한다. 코드·문서·커밋은 정상 문체를 유지한다.
