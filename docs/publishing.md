# 준비 저장소 공개 전

이 절차는 **시험 전 개인 로컬 준비 저장소**에만 적용한다. 사전체험·본시험에서는 이 문서를 근거로 공개·push하지 않는다. 그 환경에서는 모든 저장소의 push와 API/CLI를 통한 원격 쓰기·외부 업로드를 금지한다.

1. 공개 대상 계정·저장소 이름·visibility를 사용자에게 보여준다. 로그인 계정이 곧 공개 대상의 승인이라고 가정하지 않는다.
2. 공개할 파일 목록과 내용을 확인한다. 허용 범위는 일반 지침·출처·라이선스·빈 양식이다. 실제 과제·모의 실행 로그·회사 코드·개인정보·키·개인 링크·로컬 설정을 제외한다.
3. Git 이력이 있다면 현재 파일뿐 아니라 공개될 커밋에도 민감 자료가 없는지 확인한다. `.gitignore`는 비밀 보호 장치가 아니며 이미 추적된 파일을 숨기지 않는다.
4. 경로 링크, 빈 템플릿, 자동 인식 없는 사용, 기존 파일 보존과 실제 실행 검증을 확인한다. 검증 보고는 저장소 밖에 둔다.
5. 공개할 내용을 사용자가 검토한 뒤 명시적으로 확인하면 생성·push한다. 기존 공개 저장소가 있으면 이력·파일을 먼저 대조하며 덮어쓰거나 force-push하지 않는다.
6. 공개한 뒤 비로그인 공개 읽기와 사용 URL·커밋을 확인한다. 제공 환경에서 가져오기 성공은 사전체험 전까지 미확인이다.

사용한 공개 저장소는 2차 예선 결과 통지까지 공개를 유지한다. 갱신할 때는 새 revision을 모의 검증하고 시작 프롬프트에도 반영한다. 본시험 도중 작업 결과를 이 저장소로 보내지 않는다.
