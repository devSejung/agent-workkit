# Codex CLI 빠른 사용

**읽는 때:** 사용자가 CLI 조작을 묻거나 `CLI 도움말`이라고 요청할 때. 아래에서 지금 필요한 행만 보여준다. 공식 문서 기준 안내이며 제공 버전의 `/` 메뉴·`codex --help`를 확인하고 업데이트하지 않는다.

## Codex 대화 입력창

| 하려는 일 | 입력 | 알아둘 점 |
| --- | --- | --- |
| 명령 목록 보기 | `/` | 목록에서 선택하거나 이름으로 검색 |
| 현재 대화에서 다른 방향 탐색 | `/fork` | 대화를 분기. 파일 변경을 자동 격리한다고 가정하지 않음 |
| 이전 대화 이어가기 | `/resume` | 같은 대화를 다시 선택 |
| 대화가 길어졌을 때 | `/compact` | 앞선 대화를 요약. 중요한 결정·실행 상태는 로컬 기록에도 남김 |
| 세션 상태 보기 | `/status` | 현재 세션·사용량 등의 상태 확인 |
| 스킬 선택 | `/skills` | `caveman`, `explain-work` 선택 또는 `$이름`으로 호출 |
| 파일을 요청에 넣기 | `@` 후 파일 선택 | 파일 경로를 요청에 포함. 편집기에서 파일을 여는 기능과 구분 |
| 파일 내용을 바로 읽기 | `README.md를 읽고 필수 조건만 보여줘` | 일반 문장. `해당 파일 20~60행을 줄 번호와 함께 보여줘`처럼 범위 지정 가능 |

`짧게`, `서술형 대비해`, `CLI 도움말`은 이 도구함의 일반 대화 요청이며 별도의 내장 슬래시 명령이 아니다.

## 셸 터미널

Codex 대화창 밖의 셸에서 실행한다. 해당 과제 폴더로 이동한 상태를 유지한다.

| 하려는 일 | 명령 |
| --- | --- |
| 저장된 대화 선택해 재개 | `codex resume` |
| 가장 최근 대화 재개 | `codex resume --last` |
| 저장된 대화를 선택해 분기 | `codex fork` |
| 제공 버전·옵션 확인 | `codex --version`, `codex --help` |

## 파일 확인과 포크

터미널의 Ctrl+클릭 동작은 터미널·편집기 연결에 따라 다르므로 이를 필수 조작으로 삼지 않는다. 제공 환경에 파일 탐색기·텍스트 편집기가 있으면 파일 경로를 찾아 직접 연다. Codex IDE 확장을 새로 설치해야 파일을 볼 수 있는 것은 아니다. 에이전트는 변경 파일·줄 번호와 필요한 부분만 출력해 사용자가 쉽게 확인하도록 한다.

포크는 대화를 복제한다. 같은 작업 디렉터리를 고르면 두 대화가 같은 파일을 수정할 수 있다. 먼저 한쪽은 분석·질문 전용으로 두거나 파일 수정 담당을 구분한다. 작업 트리 분리가 필요한 경우에만 제공 기능·로컬 Git 상태를 확인해 분리한다. 세션이 바뀌면 실제 과제 경로·Git 상태·기록을 다시 확인한다.

CLI의 대화와 사용자의 파일 보기·내장 Browser 확인을 함께 써도 된다. 시험 작업을 개인 웹 AI나 외부 클라우드로 옮기는 대안은 사용하지 않는다. 공식 사용법은 [CLI 명령](https://learn.chatgpt.com/docs/developer-commands?surface=cli), [터미널 옵션](https://learn.chatgpt.com/docs/cli/reference)을 참고한다.
