# 과제 AGENTS.md에 넣을 블록

1. 실제 과제 루트와 적용되는 지침을 확인한다. 과제 지침 수정이 허용되고 루트 `AGENTS.md`가 적용되는 경우, 아래 마커 사이의 블록을 파일 끝에 추가한다. 파일이 없다면 블록으로 만든다. `{{START_PATH}}`에는 가져온 START.md의 실제 절대 경로를 넣고, `{{NOTES_PATH}}`에는 과제의 작업 기록 경로를 넣는다.
2. 기존 본문·줄바꿈·사용자 변경을 보존한다. 블록이 이미 일치하면 그대로 재사용한다. 경로가 바뀌어 갱신해야 하면 내용이 확인된 도구함 블록만 고친다. 불완전한 마커나 사용자 수정과 충돌하면 기존 파일을 두고 경로를 명시하는 방법을 사용한다. 작업 전후 diff를 확인한다.
3. 세팅 결과에는 연결한 파일과 실제 기록 경로를 표시한다. 파일을 쓴 상태와 새 세션에서 적용을 확인한 상태를 구분한다. 수정이 제한되거나 다른 지침 파일이 우선하면 `START.md`를 명시해 읽는 방식으로 진행한다.

## 과제 진행

- 공식·기존 과제 지침을 우선한다. 실제 마감에 맞춰 첫 전체 실행과 최종 점검 시점을 잡는다.
- README와 데이터에서 핵심 결정과 빠진 조건을 찾는다. 결과를 바꿀 질문부터 제공된 담당자에게 확인하고, 가설과 실제 답을 구분한다.
- 작업 중 새 예외·충돌이 나오면 해당 쟁점만 다시 확인한다. 답을 기다리며 가능한 실행을 진행한다. 확인한 답과 대기 중인 질문은 기록에서 이어받는다.
- 기존 코드와 적합한 공개 구현을 살펴보고 작은 변경부터 실제로 검증한다. 마감 전 필수 결과와 제출물을 확인하고 시험 중 원격 쓰기·push는 하지 않는다.
- 시작·재개 시 `{{NOTES_PATH}}`가 있으면 읽고, 확인된 조건·미답 질문·검증·다음 행동을 바뀐 부분만 남긴다. 상세 절차는 `{{START_PATH}}`에서 현재 단계에 필요한 부분을 읽는다.
